## What this tracks  
This dataset maps the grid system used to organize public hunting, fishing, and trapping access areas across Nebraska.

## Why it matters to you  
If you hunt, fish, or trap in Nebraska, this grid helps you locate specific public-access areas managed by the Game and Parks Commission and partners. Knowing your grid square ensures you're checking the right maps for permitted locations before planning a trip. Landowners near these areas can also see how public access is organized near their property.

## How to read this data  
**PageNum** — The grid section number (e.g., "4"), corresponding to a physical map page in the ATLAS system.  
**PDF_MapURL** — If populated, this would link to a downloadable map of the grid section (sample shows blank values in this dataset).  
**Shape_Area** — The size of the grid section in square units (e.g., "7987348443.53"), useful for understanding the scale of each mapped area.  

## Try it yourself  
Visit the [Nebraska Game and Parks Commission ATLAS](https://outdoornebraska.gov/atlas/) and enter your county to see which grid section covers your preferred outdoor activity areas.
