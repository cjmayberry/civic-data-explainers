## What this tracks  
This dataset maps the official boundaries of Nebraska's state game refuges, including areas like the North Platte refuge.

## Why it matters to you  
If you're hunting, fishing, or hiking near rivers in Nebraska, this data tells you exactly where state game refuge rules apply. Knowing these boundaries helps you avoid accidental trespassing or violating wildlife protection laws. Landowners adjacent to these areas can also verify if their property borders a protected zone.

## How to read this data  
**Name** — Identifies the specific game refuge (e.g., "North Platte").  
**BoundaryType** — Confirms the area's protected status (e.g., "RefugeBoundary").
