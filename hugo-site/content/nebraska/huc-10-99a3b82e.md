## What this tracks  
This dataset identifies Nebraska's hydrologic units (watersheds) using 10-digit codes that classify water drainage areas.

## Why it matters to you  
If you're buying property near Rifle Creek or the Middle Loup River, this data shows whether your land falls within a designated watershed. Farmers can check if their fields share a HUC10 code with nearby water sources, which matters for irrigation planning and conservation programs. Developers in Nebraska must consult these boundaries when assessing flood risks or stormwater management requirements.

## How to read this data  
**HUC10** — A 10-digit code like "1021000303" representing nested watershed boundaries, where the first digits show larger regional basins.  
**NAME** — The local water feature name (e.g., "Rifle Creek-Middle Loup River").  
**AREAACRES** — The watershed size in acres (e.g., 172,493 acres for the sample entry).  

## Try it yourself  
Search your Nebraska address on the USGS Watershed Map (https://water.usgs.gov/wsc/map_index.html) to find your HUC10 code and compare it with neighboring watersheds.
