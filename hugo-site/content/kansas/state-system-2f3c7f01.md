## What this tracks  
This dataset maps Kansas' 10,000-mile state highway system, including Interstates, U.S. routes, and state-numbered highways.

## Why it matters to you  
Knowing whether a road is part of the state system tells you who maintains it—KDOT handles potholes and snowplowing on these routes, not local governments. If you're planning a trucking route across Kansas, this data confirms which roads are state-maintained for weight limits and conditions. Businesses near **us_routes** like US-59 can check if their freight access depends on state upgrades.

## How to read this data  
**us_routes** — The U.S. highway number (e.g., "59" for US-59) if the segment is part of the federal highway system.  
**state_routes** — The Kansas state highway number (e.g., "15" for K-15) for locally numbered routes.  
**FromMeasure/ToMeasure** — Mile marker start/end points (e.g., 12.09 to 19.12) locating specific segments.  

## Try it yourself  
Check if your commute route is state-maintained by searching [KDOT's highway map](https://www.ksdot.org/) for the route numbers in this dataset.
