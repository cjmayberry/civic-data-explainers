## What this tracks  
This dataset maps Kansas' sub-watershed boundaries using 10-digit Hydrologic Unit Codes (HUC-10), which divide the state into smaller drainage areas.  

## Why it matters to you  
If you own farmland in Kansas, this data shows exactly which watershed your property sits in — crucial for understanding flood risks, irrigation rights, or runoff regulations. Developers can check if a parcel drains into protected waterways before planning construction. Rural residents can identify which creek or river their local water quality issues might originate from.  

## How to read this data  
**HUC_10** — A unique 10-digit code for each watershed (e.g., 1024000509).  
**HU_10_NAME** — The watershed's common name (e.g., "Little Tarkio Creek-Missouri River").  
**SQ_MILES** — The area size in square miles (e.g., 21.99), helping compare watershed scales.  

## Try it yourself  
Search your address on Kansas’ [Watershed Mapping Tool](https://www.kansasgis.org/) to see if your property is in a flood-prone HUC-10 zone.
