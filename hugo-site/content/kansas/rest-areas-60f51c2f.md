## What this tracks  
This dataset shows rest areas along Kansas state highways where drivers can stop without exiting onto local roads.  

## Why it matters to you  
Knowing where these rest areas are located helps you plan safer long-distance drives across Kansas by identifying places to stretch, use restrooms, or eat packed meals. Truckers can check parking availability before overnight stops. Families can verify ADA-accessible facilities for elderly or disabled passengers before road trips.  

## How to read this data  
**LocationDescription** — Where the rest area is (e.g., "4 MI WEST OF K-177").  
**Route** — Nearby highway (e.g., "I-70").  
**Restroom** — "Y" if available, blank if not.  
**TruckParking** — Number of semi-truck spaces (e.g., "14").  

## Try it yourself  
Before your next trip on I-70, check this dataset for rest areas west of Topeka by searching for "Route = I-70" and "County = Shawnee" (county code 31).
