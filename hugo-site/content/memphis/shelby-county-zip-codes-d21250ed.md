## What this tracks  
This dataset maps all ZIP Code Tabulation Areas (ZCTAs) in Shelby County, which closely correspond to USPS ZIP codes used for mail delivery.

## Why it matters to you  
When opening a small business in Memphis, knowing your exact ZIP code boundaries helps determine which neighborhoods you'll serve and which local regulations apply. Residents can use this to verify if they qualify for ZIP-specific programs like community grants or school enrollment zones. The geographic coordinates help delivery services pinpoint coverage areas.

## How to read this data  
**ZCTA5CE20** — The 5-digit ZIP code (e.g., 38112 for the University of Memphis area).  
**ALAND20** — Total land area in square meters (e.g., 12,446,644 for 38112).  
**INTPTLAT20/INTPTLON20** — Geographic center point coordinates (e.g., +35.1476623, -089.9763922 for 38112).
