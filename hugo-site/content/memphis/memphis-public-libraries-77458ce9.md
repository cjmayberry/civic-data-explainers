## What this tracks  
This dataset records the locations and contact details of public libraries in Memphis.

## Why it matters to you  
Knowing where your nearest library branch is located helps you plan visits for book borrowing, computer access, or community programs without unnecessary travel. For small business owners, libraries offer free meeting spaces and business resources — this data tells you which location is closest to your shop. Parents can check which branch has the shortest commute for after-school programs.

## How to read this data  
**user_name** — The library branch name (e.g., "Cherokee Library").  
**staddr** — The street address (e.g., "3300 Sharpe Avenue").  
**user_phone** — Direct contact number for the branch (e.g., "901-415-2762").  

## Try it yourself  
Find the library closest to your home by searching [Memphis's library map](https://www.memphislibrary.org/locations/) for your ZIP code or street address.
