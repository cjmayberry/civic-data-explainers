## What this tracks  
This dataset maps state-owned land parcels in Nevada, including ownership details and acreage.

## Why it matters to you  
If you're considering leasing land near Reno-Tahoe Airport for a business, this data shows which parcels are already state-controlled. Knowing the exact acreage and agency managing a plot (like the Motor Pool) helps assess expansion potential before contacting officials. Homeowners near these areas can check if bordering vacant land is publicly owned when planning property improvements.

## How to read this data  
**APN** — The Assessor's Parcel Number (e.g., 015-210-34_W) used to reference the property in county records.  
**OWNER** — Which Nevada agency controls the land (e.g., "RENO-TAHOE AIRPORT AUTHORITY").  
**COMMON_NAM** — Descriptive name of the property's use (e.g., "Reno Motor Pool - Airport Authority property").  
**CALC_ACRES** — The GIS-calculated land area (e.g., 1.0115 acres), which may differ from assessed values.

## Try it yourself  
Search the dataset using the APN from your property tax statement to see if adjacent land is state-owned.
