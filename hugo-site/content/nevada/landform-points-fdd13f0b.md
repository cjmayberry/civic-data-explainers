## What this tracks  
This dataset records natural landform features like mountains and peaks across Nevada, including their names and elevations.

## Why it matters to you  
Hikers can check exact elevations before planning routes to gauge difficulty. Local tour operators can verify landmark names when creating outdoor adventure packages. Homebuyers near mountainous areas can assess terrain elevation when evaluating properties. Nevada residents exploring public lands can identify nearby natural features for weekend trips.

## How to read this data  
**NAME** — Official geographic feature name (e.g., "Bearing Peak").  
**ELEVATION_** — Height in feet above sea level (e.g., "2520").  
**DATA_SOURC** — Which organization mapped the feature (e.g., "USGS 24K" for U.S. Geological Survey).
