## What this tracks  
This dataset records water-related geographic features in Nevada, such as rivers, lakes, or springs.

## Why it matters to you  
If you're buying property near a water feature, this data tells you whether that "seasonal creek" on the listing is officially mapped as a waterway. Developers can check if land has protected wetlands before planning projects. Hikers can verify if a trail crosses a documented stream before heading out.

## How to read this data  
**HYDRO_TYPE_TEXT** — The type of water feature (e.g., "River", "Lake"). Sample values show some entries are blank.  
**HYDRO_CATEGORY** — A numeric code classifying the water feature. "4" in samples suggests this may indicate man-made features like canals.  
**State** — Always "32" in samples, likely a code representing Nevada.  

## Try it yourself  
Check if your neighborhood has any mapped water features by searching the Nevada Open Data portal for hydrography layers near your address.
