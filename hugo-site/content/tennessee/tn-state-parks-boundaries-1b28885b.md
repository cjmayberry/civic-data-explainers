## What this tracks  
This dataset maps the official boundaries of all Tennessee State Parks.

## Why it matters to you  
If you're planning a hike, picnic, or camping trip, this data shows exactly where each park's land begins and ends — crucial for knowing where you can legally explore. For nearby landowners, it clarifies where private property meets protected state land. Businesses offering outdoor gear rentals or guided tours can use this to verify which parks fall within their service areas.

## How to read this data  
**PARK_NAME** — Official name of the state park (e.g., "Chickasaw State Park").  
**TSP_UID** — Unique park identifier starting with "TSP-" (e.g., "TSP-0055").  
**Acres** — Total park size in acres (e.g., 1356.14).

## Where this leaves you  
This dataset doesn't let you look anything up by your address, but it's still a window into how the state operates. Read it to understand the scope of the program and what the official records contain; the state's own interactive map (linked on this page) shows the locations involved.
